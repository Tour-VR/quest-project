## 1. Objetivo

Levar o visitante remoto para dentro do campus. Em `/vr/:slug`, o panorama 360° do ponto
envolve a pessoa:

- no computador ou no celular, ela olha em volta arrastando a imagem;
- no Meta Quest 3, toca em **Entrar em VR** e olha em volta virando a cabeça.

Um painel mostra nome e resumo do lugar, e a visita é registrada como `vr`. A navegação
entre pontos fica para o plano 021.

## 4. Escopo

**Dentro:**

- dependências three.js / React Three Fiber / drei / @react-three/xr;
- rota `/vr` (lista de pontos com panorama) e `/vr/:slug` (cena), **carregadas sob demanda**;
- esfera invertida com a textura equirretangular, orientada pela regra do plano 019;
- olhar em volta arrastando (modo não imersivo);
- botão **Entrar em VR**, só quando o navegador suportar `immersive-vr`;
- painel de informação em HTML (fora do VR) e em 3D (dentro do VR);
- registro de visita `vr`;
- função pura `yawToPosition`, que o plano 021 usa para posicionar as setas;
- E2E não imersivo.

**Fora:**

- setas das conexões e navegação entre pontos: plano 021;
- áudio, narração, vídeo 360°: não previstos;
- modo `immersive-ar` (passthrough): fora do produto (ADR-0006);
- controle por *teleporte* ou locomoção: o visitante fica no centro da esfera.

## 5. Decisões tomadas no planejamento

| Questão | Decisão | Motivo |
|---|---|---|
| Bibliotecas | `three` `^0.175.0`, `@react-three/fiber` `^9.1.0`, `@react-three/drei` `^10.0.0`, `@react-three/xr` `^6.6.0`, `@types/three` na mesma série do `three` | Séries compatíveis com React 19 |
| Conferência das versões | Antes de instalar, `npm view <pacote> peerDependencies` para os quatro; R3F 9 exige React 19; drei 10 e xr 6 exigem R3F 9. **Conflito = parar** | Instalação forçada quebra em execução |
| Carregamento | `React.lazy` em `src/modes/vr/VrRoutes.tsx`; rotas `/vr/*` envolvidas em `<Suspense fallback={<LoadingState />}>` | three.js tem centenas de KB; o modo AR não deve baixá-lo |
| Esfera | `SphereGeometry(PANORAMA_RADIUS=500, 60, 40)`, `geometry.scale(-1, 1, 1)`, `MeshBasicMaterial` com a textura, `rotation.y = PANORAMA_ROTATION_Y = -Math.PI / 2` | Com escala `-1` em X e rotação de -90°, o **centro da imagem fica à frente** da câmera inicial (que olha para `-Z`) e a direita da imagem fica à direita (+X): bate com o `yaw` do plano 019 |
| Textura | Carregada por `usePanoramaTexture(url)` com `TextureLoader.loadAsync`, `colorSpace = SRGBColorSpace`, estado `AsyncState` | Erro de carregamento vira mensagem, sem *error boundary* |
| `yaw` → posição | `yawToPosition(yawDegrees, radius, height)` = `[radius·sin(yaw), height, −radius·cos(yaw)]` | 0° à frente, positivo à direita, ±180° atrás |
| Olhar em volta | `OrbitControls` do drei: `enableZoom={false}`, `enablePan={false}`, `rotateSpeed={-0.4}`, câmera em `[0, 0, 0.1]` olhando para a origem | Arrastar "puxa" a paisagem, como nos visualizadores 360° conhecidos |
| VR | `const xrStore = createXRStore()` no módulo; `<XR store={xrStore}>` dentro do `<Canvas>`; botão chama `xrStore.enterVR()` | API da @react-three/xr 6 |
| Suporte a VR | Hook `useImmersiveVrSupport()` com `navigator.xr?.isSessionSupported('immersive-vr')`; botão só aparece se `true` | Navegadores sem WebXR não mostram um botão quebrado |
| Painel em VR | `Text` do drei com nome e resumo, a `INFO_PANEL_DISTANCE = 2` m à frente e um pouco abaixo dos olhos, fundo semitransparente | HTML não aparece dentro da sessão imersiva |
| Ponto sem panorama | Mensagem "Este ponto ainda não tem visita 360°." + link para `/p/:slug` | Evita tela preta |
| Cobertura | `src/modes/vr/scene/**` (componentes que só montam a cena 3D) fica fora da cobertura unitária e é coberto por E2E e teste manual. Esses arquivos **não podem conter lógica**: toda conta e toda decisão ficam em funções/hooks testados | jsdom não tem WebGL; a lógica continua com 80% |
| Painel HTML | `PointHeader` do plano 017 sobre o canvas, recolhível ("Mostrar/ocultar informações") | Reaproveita o núcleo |

### Passo 2 — Constantes e funções puras

`src/modes/vr/constants.ts`:

```ts
export const PANORAMA_RADIUS = 500;
export const PANORAMA_WIDTH_SEGMENTS = 60;
export const PANORAMA_HEIGHT_SEGMENTS = 40;
/** Coloca o centro da imagem equirretangular a frente da camera inicial (-Z). */
export const PANORAMA_ROTATION_Y = -Math.PI / 2;
export const CAMERA_START: [number, number, number] = [0, 0, 0.1];
export const ORBIT_ROTATE_SPEED = -0.4;
export const INFO_PANEL_DISTANCE = 2;
export const INFO_PANEL_HEIGHT = -0.3;
```

`src/modes/vr/geometry.ts`:

```ts
const DEGREES_TO_RADIANS = Math.PI / 180;

/** Converte o angulo da conexao (plano 019) em posicao na cena. 0 = frente, positivo = direita. */
export function yawToPosition(yawDegrees: number, radius: number, height: number): [number, number, number] {
  const yaw = yawDegrees * DEGREES_TO_RADIANS;
  return [radius * Math.sin(yaw), height, -radius * Math.cos(yaw)];
}

/** Rotacao em Y para um objeto na posicao do yaw ficar de frente para o centro. */
export function facingCenterRotationY(yawDegrees: number): number {
  return -yawDegrees * DEGREES_TO_RADIANS;
}
```

### Passo 3 — Hooks

- `src/modes/vr/hooks/usePanoramaTexture.ts`: recebe `url | null`; com `null` devolve
  `{ status: 'not-found' }`; senão carrega com `new TextureLoader().loadAsync(mediaSrc(url))`,
  aplica `SRGBColorSpace`, descarta a textura (`texture.dispose()`) ao trocar de URL ou
  desmontar.
- `src/modes/vr/hooks/useImmersiveVrSupport.ts`: `boolean | null` (null enquanto verifica).
- `src/modes/vr/hooks/useVrPoints.ts`: `usePublicPoints()` filtrado por `has_panorama`.

### Passo 4 — Componentes da cena (sem lógica)

Em `src/modes/vr/scene/`:

- `PanoramaSphere.tsx`: `<mesh rotation-y={PANORAMA_ROTATION_Y}>` com a geometria (criada
  em `useMemo`, com `scale(-1, 1, 1)`) e `<meshBasicMaterial map={texture} />`;
- `InfoPanel3D.tsx`: `<group position={[0, INFO_PANEL_HEIGHT, -INFO_PANEL_DISTANCE]}>` com
  um plano escuro semitransparente e dois `<Text>` (nome, resumo); visível só durante a
  sessão imersiva (`useXR((s) => s.session)` não nulo);
- `VrCanvas.tsx`:

```tsx
export const xrStore = createXRStore();

export function VrCanvas({ texture, name, summary }: VrCanvasProps) {
  return (
    <Canvas camera={{ position: CAMERA_START, fov: 75 }} data-testid="vr-canvas">
      <XR store={xrStore}>
        <PanoramaSphere texture={texture} />
        <InfoPanel3D name={name} summary={summary} />
        <OrbitControls enableZoom={false} enablePan={false} rotateSpeed={ORBIT_ROTATE_SPEED} />
      </XR>
    </Canvas>
  );
}
```

O `fov: 75` vai para `constants.ts` como `CAMERA_FOV`.

## 11. Riscos e pontos de atenção

- **Tela preta no Quest.** Quase sempre é panorama grande demais (> 4096 px) ou página em
  HTTP. Teste com o arquivo de 2048×1024 primeiro.
- **Imagem espelhada** (textos de placas ao contrário): falta o `scale(-1, 1, 1)`.
- **Vazamento de memória ao trocar de ponto:** `texture.dispose()` no hook; o plano 021
  troca de ponto sem recarregar a página e depende disso.
- **`OrbitControls` dentro do VR:** a @react-three/xr controla a câmera durante a sessão;
  se a imagem "brigar" com o movimento da cabeça, renderize o `OrbitControls` só quando
  `useXR((s) => s.session)` for nulo. Isso fica no componente de cena e não é lógica de
  negócio.
- **Certificado no Quest:** o navegador do Quest pede para aceitar o certificado
  autoassinado uma vez por endereço. Sem isso, não há WebXR.

## 12. Verificação pelo aluno

1. No painel, garanta que um ponto publicado tem panorama (plano 019).
2. No computador, abra `http://localhost:3001/vr`: o ponto aparece na lista. Clique nele.
3. A foto 360° ocupa a tela. Arraste com o mouse: você olha em volta. Para cima e para
   baixo também funciona.
4. **No celular** (com `npm run dev:https` rodando e o IP da máquina): abra
   `https://<IP>:3001/vr/<slug>` e arraste com o dedo.
5. **No Meta Quest 3**, com o óculos no mesmo Wi-Fi:
   1. abra o app **Navegador** (Browser);
   2. digite `https://<IP>:3001/vr/<slug>`;
   3. no aviso de segurança, escolha **Avançado** → **Continuar**;
   4. toque em **Entrar em VR** e permita;
   5. vire a cabeça: o campus está à sua volta, e à frente aparece o painel com o nome
      do lugar;
   6. para sair, aperte o botão Meta no controle direito.
6. Anote no grupo se o painel ficou legível e se a imagem estava nítida.
